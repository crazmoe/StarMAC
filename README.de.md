# StarMAC

[English](README.md) · **Deutsch**

StarMAC ist ein freier macOS-Client für STARFACE-Telefonanlagen. Er ist die macOS-Portierung von
[StarCLX](https://github.com/crazmoe/StarCLX) und geht denselben Weg wie die Windows-Portierung
[StarCMX](https://github.com/crazmoe/StarCMX): gleiche Funktionen, gleiche Schnittstellen
(OneHub gRPC, SIP/TLS mit SRTP, XMPP-Chat), STARFACE 10 und neuer.

Kein Angebot der STARFACE GmbH. „STARFACE“ wird nur beschreibend verwendet. StarMAC ist nicht
die offizielle STARFACE App für macOS und ersetzt sie nicht.

> **Stand:** Einrichtung. Das Repository wird vorbereitet; ein Release gibt es noch nicht.
