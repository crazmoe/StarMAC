# StarMAC

**English** · [Deutsch](README.de.md)

StarMAC is a free macOS client for STARFACE phone systems. It is the macOS port of
[StarCLX](https://github.com/crazmoe/StarCLX) and follows the same approach as the Windows port
[StarCMX](https://github.com/crazmoe/StarCMX): same features, same interfaces (OneHub gRPC,
SIP/TLS with SRTP, XMPP chat), STARFACE 10 and later.

Not affiliated with STARFACE GmbH. "STARFACE" is used for descriptive purposes only. StarMAC is
not the official STARFACE App for macOS and does not replace it.

> **Status:** setup. The repository is being prepared; there is no release yet.
